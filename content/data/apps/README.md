# Copernicus applications learning catalogue

`catalogue.json` records the 11 entries observed at
[Copernicus Data Stores Applications](https://apps.climate.copernicus.eu/) on
20 November 2026. Names, URLs, service labels, and dataset identifiers are factual
metadata from that catalogue. Questions, limitations, and teaching themes are
original project annotations, not official app classifications or ratings.

Credit ECMWF's Copernicus Data Stores Applications team, C3S/CAMS, and the
individual app and dataset contributors. Use each app's About/credits and the
linked dataset terms before downloading or reusing its outputs. A catalogue
listing is not a licence covering every app's data, media, or basemap.

No publisher descriptions, screenshots, logos, app source code, or external app
data are bundled here. The catalogue is a dated teaching index, not a guaranteed
API or exhaustive future listing. Missing dataset IDs mean “not listed in this
catalogue entry,” not “no source data.”
